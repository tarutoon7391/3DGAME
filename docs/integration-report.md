## 全体の残課題

1. **手触りは未確認**：自動操作のブラウザでは rAF が約2fpsに間引かれるため、FPS・難易度・テンポ・カメラはどのワーカーも実測できていない。監査もコードを読んだ静的確認のみ。**人間が公開URLで5本を遊んで確認する必要がある**
2. **shared/ui.js の不具合（manager の実装ミス）**：オーバーレイがスタイル層の外に置かれるため、パネル見出し（h1/h2）の文字色が黒になる。thief は自前で色を上書きして回避、他の4本は影響あり
3. **shared の「ハブへ戻る」は保存せず遷移する**：最後のセーブ以降の進行が失われる（rpg・farm で影響）
4. **オンライン土台は未マージ**：`feat/online-base` は5本マージ後に main へマージする予定（計画書 §10）
