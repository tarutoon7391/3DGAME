# RPG 職業96種の仕分け（7カテゴリ）

数値は現在の main（090aa38）の実データ。近接は MELEE_BUFF を掛けた後の値。

## カテゴリの定義

| カテゴリ | 定義 |
|---|---|
| アタッカー | 近接の通常攻撃で火力を出す職 |
| ガンナー | 飛び道具・魔法・設置物で火力を出す職（遠距離火力） |
| タンク | 被ダメ軽減・挑発・高HPで前に立つ職 |
| ヒーラー | 味方のHP回復・バリア・蘇生が主な仕事の職 |
| バッファー | 味方の攻撃力・移動・ゲージ・クールダウンを上げる職 |
| デバッファー | ボスを鈍らせる・もろくする・弾幕を弱める職 |
| ユニーク | ランダム性や特殊な仕組みが主役で、役割に収まらない職 |

## 迷った職（変えてもいい）

- 踊り子・先駆け：R が全体バフだけど、普段の仕事は近接火力なのでアタッカー
- 鎖鎌使い：鈍化はあるが、飛びつき火力が主なのでアタッカー
- 呪術師：回復はおまけ程度。デバッファー寄りにしてもいい
- 天候術士：回復も火力も中途半端。ヒーラーかガンナーに寄せて作り直す候補
- 鏡術師・メイド：弾消しの守り役。数が増えるなら「守護」カテゴリを作ってもいい
- 剣闘士・修羅：火力も高い。タンクとしての役割（挑発など）を足すか、アタッカーに移すか
