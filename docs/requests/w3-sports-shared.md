# w3-sports：shared への要望

## 1. showPause にボタンを追加できるようにしてほしい（extraButtons）
- 何が欲しいか：`showResult` と同じ `extraButtons: [{label, onClick}]` を `showPause` でも使えるように
- なぜ：スポーツはポーズ中に「競技選択へ」戻りたい（今は「最初から」か「ハブへ戻る」しかない）
- 現在の回避策：ポーズからは「最初から」で再戦、競技選択へは結果画面から戻る

## 2. 汎用メニュー（複数選択肢のオーバーレイ）
- 何が欲しいか：`showTitle` のようなパネルで、任意個の選択ボタン（カード型）を出す関数
- なぜ：競技選択・難易度選択のような「選んで進む」画面が必要
- 現在の回避策：`games/sports/src/core/menu.js` に g3-* のスタイルを流用した独自オーバーレイを実装

## 3. input に「入力をデータ化」するヘルパー（オンライン化向け・任意）
- 何が欲しいか：押下キー・マウスの状態をまとめて素のオブジェクトで返す `input.snapshot()` のようなもの
- なぜ：§10 の努力目標（入力の読み取りと状態更新の分離）を各ゲームで同じ形にしたい
- 現在の回避策：競技ごとに `readInput()` でコマンドに変換している
