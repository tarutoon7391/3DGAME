# docs/requests/

ワーカーから manager への依頼メモ置き場。

- ファイル名：`<ワーカー名>-<内容>.md`（例：`w1-rpg-shared.md`）
- ワーカーは**新規作成のみ**可（他人のメモ・既存ファイルは編集しない）
- 書いたら返事を待たずに作業を続ける（shared の不足は自分の `games/<slug>/src/` 内で補う）
- `audit/` は auditor（監査）のレポート置き場：`audit/<ワーカー名>.md`

## 書式

```
# <ワーカー名>：<件名>
- 何が欲しいか／困っていること
- なぜ（どのゲームのどの機能で必要か）
- 現在の回避策
```
