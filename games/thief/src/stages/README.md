# ステージ定義

`stageN.js` を作って `index.js` の配列に足すだけで追加できる（ゲーム本体のコード変更は不要）。

## map の凡例（1文字 = 1タイル、全行同じ長さ、外周は壁にする）

| 文字 | 意味 |
|---|---|
| `#` | 壁 |
| `.` | 床 |
| `,` | 物陰（暗い床。見つかりにくい） |
| `P` | プレイヤー開始位置 |
| `X` | 出口 |
| `o` | 扉（F で開閉。警備員も開ける） |
| `D` | 鍵付き扉（カードキーが必要。警備員は通れない） |
| `K` | カードキー |
| `T` | メインのお宝（必須・1つ） |
| `t` | サブのお宝（任意） |
| `S` | 展示台（しゃがむと陰に隠れられる） |
| `L` | ロッカー（隣で F：隠れる） |
| `=` | 圧力床（踏むと警報） |

## 配置データ

- `guards`: `{ route: [[c,r],...], wait }` 巡回ルート（タイル座標・ループ）と各地点での待ち秒
- `cameras`: `{ at:[c,r], dir, sweep, speed }` dir は度（0=右/+x、90=下/+z）、sweep は首振りの片側角度（度）
- `lasers`: `{ from:[c,r], to:[c,r], mode }` mode は `always`／`blink`（`on`/`off`/`phase` 秒）／`move`（`axis`:'x'|'z', `range`, `speed`）。両端は半タイル延長される
- `lights`: スポットライトを当てるタイル（明るい所は見つかりやすい）
- `tips`: `{ at, r, text }` 近づくと一度だけ出るヒント（r はタイル数）
- `treasureNames`: お宝の名前（sub は `t` を左上から行ごとに読む順）
- `par`: 目標秒数、`gadgets`: `{ coin, smoke }` 使用回数
