# 怪盗ナイト（games/thief）

夜の美術館に忍び込み、警備員・監視カメラ・トラップを避けてお宝を盗み、出口から脱出するステルスゲーム。全3ステージ。

## 操作

| キー | 動作 |
|---|---|
| WASD／矢印 | 移動（カメラの向き基準） |
| Shift | 走る（速いが足音が大きく、見つかりやすい） |
| C／Ctrl | しゃがみ（C は切替、Ctrl は押している間。遅い・静か・見つかりにくい） |
| F | 盗む・カードキーを取る・扉の開閉・ロッカーに隠れる／出る |
| 1 | おとりコイン（向いている方へ投げる。落ちた音で警備員を誘導） |
| 2 | 煙玉（足元に煙。約6秒間、煙の中・向こうは見えない） |
| Q／E | カメラ回転 |
| ホイール | ズーム |
| M | 消音 |
| Esc | ポーズ |

## 流れ

タイトル（操作説明）→ ステージ選択（ベストランク表示）→ プレイ → リザルト（ランク・ベスト更新）→ もう一度／次のステージ／ステージ選択／ハブへ戻る。捕まると「つかまった…」画面からステージ最初からやり直し。

## 仕様

- **視点**：斜め見下ろしの三人称。壁の陰でもプレイヤーの位置がわかるよう、頭上に深度無視の目印を出している
- **警備員 AI**：巡回 → 不審（足音・一瞬の視認・コインで立ち止まって振り向く）→ 調査（その地点へ行く）→ 追跡（警戒ゲージ満タン＝発見）→ 見失うと捜索（周辺をうろつく）→ 巡回復帰
  - 視野コーンを床に表示。各レイをタイルマップの DDA レイキャストで壁に当てて切るので、壁越しには見えない（見た目と判定が一致）
  - 警戒ゲージは距離が近いほど・明るいほど速く溜まる。頭上に「？」（ゲージ量で濃さが変わる）／「！」（発見）
  - 追跡中に見られながらロッカーへ入ると引きずり出される（捕まる）
  - 普通の扉は警備員も開けて通る。鍵付き扉は通れない
- **見つかりやすさ**：走る 1.25／歩く 1.0／しゃがみ 0.55、止まっていると ×0.85、スポットライト外 ×0.75、物陰（暗い床）×0.6、展示台の近くでしゃがむと ×0.45。しゃがみ中は展示台・展示ケースが視線を遮る
- **足音**：歩き半径 3.2、走り半径 8.5、しゃがみは無音。床に波紋で表示（白＝歩き、橙＝走り、黄＝コイン、青＝警備員、赤＝警報）。壁越しの音は届く範囲が 0.6 倍
- **監視カメラ**：首振り・赤い視野コーン。ゲージ満タンで警報 → 近くの警備員が駆けつける
- **レーザー**：常時／点滅／移動の3種。触れると警報
- **圧力床**：踏むと警報
- **鍵付き扉とカードキー**：カードキーを拾うと全ての鍵付き扉が開けられる
- **隠れ場所**：ロッカー（完全に隠れる）、展示台の陰・物陰（見つかりにくい）
- **ガジェット**：おとりコイン・煙玉。回数はステージごとに決まっている（HUD に表示）
- **目標**：メインのお宝（必須）＋サブのお宝（任意）→ 出口（緑）で脱出
- **評価**：回収率 40点＋発見回数 30点（1回ごとに −12）＋時間 30点（目標秒数以内で満点、2倍で0点）。S≥90／A≥70／B≥50／C。ステージ別ベスト（点数が高い方）を `3dgame:thief` に保存
- **演出**：発見時の「！」・警報音・赤い画面フラッシュ・画面揺れ、追跡中は緊迫BGM、暗い館内のスポットライト、警備員の懐中電灯、お宝を盗んだ時のキラキラ

## ステージ

`src/stages/` にタイルマップ＋配置データで定義（書式は `src/stages/README.md`）。コードを触らず追加できる。

1. 小さな画廊（チュートリアル：警備員1・カメラ1、近づくとヒント表示）
2. 夜の展示ホール（警備員2・カメラ2・点滅／常時レーザー・圧力床・カードキー）
3. 大美術館の宝物庫（警備員4・カメラ3・常時／点滅／移動レーザー・圧力床・カードキー・ロッカー）

## ファイル構成

- `main.js` 起動だけ
- `src/app.js` 画面の流れ・入力の読み取り（intent 化）・HUD
- `src/session.js` 1ステージ分のルール進行（状態は `state` にまとめ、`snapshot()` で JSON 化可能）
- `src/grid.js` タイルマップ・衝突・DDA レイキャスト・BFS 経路探索
- `src/level.js` ステージの見た目と静的オブジェクト
- `src/player.js` / `src/guards.js` / `src/security.js` / `src/gadgets.js` 各要素
- `src/cone.js` 床の視野コーン、`src/fx.js` 波紋・粒子・揺れ、`src/sfx.js` 効果音と BGM、`src/view.js` カメラ
- `src/screens.js` ステージ選択・操作ヒント・警報フラッシュ、`src/rank.js` 評価と保存

## 決めたこと

- 発見回数には「警備員に見つかった」に加えて「カメラ・レーザー・圧力床で警報が鳴った」も数える
- ステージはすべて最初から選べる（ロックなし）。人間が公開URLで手早く確認できるようにするため
- しゃがみは C で切替、Ctrl は押している間。Ctrl+W などブラウザのショートカットは止められないので C を推奨
- コインは「向いている方向」へ投げる（マウスは使わない）。壁の手前で落ちる
- 捕まったらリザルト画面を挟んでステージ最初から（即リスタートではない）
- `?debug` を付けて開くと `window.__thief` にセッションが出る（動作確認用。通常プレイには影響なし）
- オンライン化の下準備（努力目標）：プレイヤーは `players` 配列で持ち、自分の番号は `me` 変数。入力は `readIntent()` で intent（データ）にしてから `session.update(dt, time, intents)` に渡す
