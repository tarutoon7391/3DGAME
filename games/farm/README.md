# のんびり農場（games/farm）

斜め見下ろし視点の3D農場ゲーム。畑を耕して作物を育て、出荷と依頼でお金と農場EXPを稼ぎ、ショップで道具・畑・動物を増やしていく。
区切りの目標は **農場レベル5**（到達でクリア画面）。その後も同じセーブで続けて遊べる。

## 操作

| キー | 動作 |
|---|---|
| WASD／矢印 | 移動 |
| F／左クリック | 目の前のマスに道具を使う（成熟した作物は収穫、生産物は拾う、ジョウロ＋井戸で給水） |
| 1〜5 | 道具切替：1 クワ／2 ジョウロ／3 タネ／4 カマ／5 エサ（3 をもう一度押すとタネの種類を切替） |
| E | 話す・調べる：ショップ／出荷箱／依頼ボード／ベッド（就寝）／井戸／動物をなでる |
| Tab | 持ち物（タネの選択・食べ物を食べる） |
| ホイール | ズーム |
| Esc | ポーズ（メニューを開いているときは閉じる） |

## 遊び方の流れ

1. 畑（木の枠の中）を **クワ** で耕す → **タネ** をまく → **ジョウロ** で水やり（空になったら井戸で給水）
2. 家のベッドで **E** → 寝ると翌日へ。水をやったマスだけ1日成長する（雨の日は全マス自動で水やり済み）
3. 育ったら **F** で収穫 → **出荷箱** に入れると翌朝入金、または **依頼ボード** で納品して報酬＋EXP
4. お金でタネ・道具強化・畑の拡張・ニワトリ／ウシを買う。農場レベルで新しい作物や拡張が解放される

最初の1件目の依頼は「カブ3個」。カブは2日で育つので、序盤10分（2日＋α）で最初の収穫・出荷・納品まで届く。
画面左上の「👉」が最初の出荷までの次の手順を案内する。

## 仕様

- **時間**：1日 = 現実の約5分（6:00〜翌2:00、1時間 = 15秒）。空の色・太陽の向き・光の強さが朝→昼→夕→夜で変化し、夜は街灯が点く。2:00 を過ぎると力尽きて翌朝（スタミナ半分）
- **天気**：晴れ／雨（雨は 30%・1日目は必ず晴れ）。雨は雨粒パーティクルと暗い空、耕したマスは全部濡れる
- **作物6種**（`src/data/crops.js`）：カブ・ジャガイモ（Lv1）、トマト（Lv2・2日ごとに何度でも収穫）、トウモロコシ（Lv3）、カボチャ（Lv4）、メロン（Lv5）。見た目は 種→芽→成長中→収穫可 の4段階
- **スタミナ**：最大100。クワ・ジョウロ・カマで減る（強化した道具は範囲が広いぶん消費も多い）。食べ物（作物・卵・牛乳・おにぎり・おべんとう）か就寝で回復。0 だと道具が使えず歩きも遅い
- **道具強化**：クワ／ジョウロ 銅（前方3マス）・金（前方3×3）。ジョウロは容量も増える
- **畑の拡張**：6×6 → 8×8 → 10×10 → 12×12
- **動物**：ニワトリ（Lv2・最大4）／ウシ（Lv3・最大2）。毎日「エサ」道具で飼料を与えると翌朝 卵／牛乳 が地面に出る。なでる（1日1回）とエサでなつき度が上がり、30以上で「良い」、70以上で「極上」品質（売値1.5倍／2倍）。エサを忘れた日はなつき度が下がり生産なし
- **依頼ボード**：常に3件。解放済み作物と飼っている動物の生産物から出題。達成で報酬金と農場EXP、すぐ次の依頼が貼られる
- **農場レベル**：EXP = 出荷額×0.25 ＋ 依頼のEXP。Lv2:80／Lv3:280／Lv4:650／Lv5:1300、以降 +900 ごと
- **セーブ**：就寝時に自動セーブ（`3dgame:farm`）。畑の全マス・所持品・道具・お金・日付・天気・動物（なつき度・位置）・地面の生産物・依頼を保存。タイトルに「つづきから」
- **画面の流れ**：タイトル（操作説明）→ プレイ → 就寝ごとに「1日のリザルト」→ 翌朝へ。Lv5 到達でクリアのリザルト（続けて遊ぶ／最初から／ハブへ戻る）。ポーズからも「最初から」「ハブへ戻る」

## ファイル構成

- `main.js` 起動だけ
- `src/game.js` メインループ（入力の読み取り `readIntent` → 状態更新 `step` → 見た目 `render`）と1日の流れ
- `src/state.js` ゲーム状態（1つの JSON 化できるオブジェクト）と所持品操作
- `src/data/` バランス数値（作物・アイテム・価格・解放条件・時間・スタミナ・依頼）
- `src/world.js` ステージ（家・店・出荷箱・ボード・井戸・囲い・木・草は InstancedMesh）
- `src/field.js` 畑のロジックと描画（土・作物はすべて InstancedMesh）
- `src/player.js` `src/animals.js` `src/sky.js` `src/particles.js` `src/sound.js`
- `src/actions.js` 道具を使う／調べる、`src/menus.js` `src/panel.js` メニューUI、`src/hud.js` HUD、`src/quests.js` 依頼

## 決めたこと

- 「F またはクリックで道具を使う」に加えて、成熟した作物はどの道具でも F で収穫できる（クワのときは耕せない場合のみ収穫）。カマは未成熟の作物を抜く（誤操作防止に2回押し）・耕した土を戻す用途
- ベッドは家の中。家に入ると屋根が透ける
- メニュー（店・出荷箱・依頼・持ち物）を開いている間は時間が止まる
- 出荷箱の中身は翌朝入金。売上と農場EXPは「1日のリザルト」で表示
- 畜産物は品質違いを別アイテムにし、依頼では品質を問わず数える（低品質から消費）
- shared の toast は画面下中央に出るので、道具バーは左下、操作ヒントは右下に置いた
- オンライン化の努力目標（manager 連絡）に合わせ、状態は `state` 1オブジェクト、入力読み取りと更新を分離、プレイヤーは `players` 配列で持つ
- URL に `?debug` を付けたときだけ `window.__farm`（フレーム手動送り・テレポート）を出す。自動テストで rAF が間引かれる環境向けの動作確認用
