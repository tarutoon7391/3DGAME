# 3DRPG 〜魔窟の主〜（games/rpg）

三人称視点のアクション。迷路を進みながら魔物と戦い、ステージ3の奥にいるボス「魔窟の主ガルドラ」を倒せばクリア。育成（レベル・経験値）も、お金・アイテム・クエストもない。

## 操作

| キー | 動作 |
|---|---|
| WASD／矢印 | 移動（カメラ基準） |
| Shift | ダッシュ（押している間。スタミナを使う） |
| マウス | カメラ（画面クリックで視点ロック。ロックしない場合は右ドラッグ） |
| ホイール | カメラ距離 |
| 左クリック | 攻撃（連打で3段コンボ。3段目は強攻撃） |
| Space | 回避（約0.4秒の無敵時間。スタミナを使う） |
| Q | 回転斬り（周囲攻撃／クールダウン5秒） |
| E | 衝撃波（前方へ貫通する斬撃／クールダウン7.5秒） |
| F | 看板を調べる |
| Esc | ポーズ（視点ロック中はロック解除で自動的にポーズ） |

## 流れ

タイトル（操作説明・つづきから）→ ステージ1「迷いの森」→ ステージ2「岩の迷宮」→ ステージ3「魔窟」でボス撃破 → リザルト（プレイ時間・撃破数・やられた回数）→「はじめから遊ぶ」／ハブへ戻る。
やられるとリザルト「やられてしまった……」→「入口からやり直す」で、いまのステージの入口から再挑戦（HP 全快、魔物・結界・ボスは元に戻る）。

## 仕様

- **ステージ1・2（迷路）**：シードから作る完全迷路（道が分かれて行き止まりも多いが、出口への正解ルートは1本）。正解ルート上に赤い**結界**が3つあり、そばにいる番人（2〜4体）を全部倒すと消える。脇道にも雑魚がうろつく。北端の青いゲートで次のステージへ
- **ステージ3（魔窟）**：旧仕様と同じ構造（入口通路・柱の大広間・ボス部屋）。レバーと宝箱は撤去し、ボス部屋の扉は最初から開いている。部屋に入ると扉が閉まって戦闘開始
- **プレイヤー**：能力値は固定（旧仕様の Lv4＋木の剣・布の服 相当。最大 HP 120、攻撃 15）。装備は変えられない
- **スタミナ**：最大 100。ダッシュ中は毎秒 22、回避1回で 30 減る。使わずに 0.6 秒たつと毎秒 30 回復。0 になると**バテ**：移動が 55% に落ち、ゲージが満タンに戻る（毎秒 22 回復、約4.5秒）まで回避もダッシュもできない。バテ中はゲージがオレンジになり「バテ！」と点滅する
- **被ダメージ**：雑魚の攻撃は1発で最大 HP の 1/4（30）、ボスの攻撃は1発で 1/3（40）。防御力の計算はない
- **回復**：回復薬はない。次のステージに入ったときと、やられて入口からやり直すときに HP が全快する
- **敵**：近接（スライム／ガイコツ兵）、遠距離（ゴブリン弓兵／亡霊術師）、突進（イノシシ／岩ゴーレム）。攻撃前に体が赤く点滅し、地面に赤い予兆（扇・直線）が出る。壁越しにはこちらに気づかず、見失うと最後に見た場所まで追ってくる
- **ボス**：薙ぎ払い（前方扇）／魔弾の輪（全方位弾）／跳躍叩きつけ（着地点に赤円）。HP 50% で怒り（咆哮・行動が速くなる・叩きつけ後に弾・ガイコツ兵を召喚・魔弾が2波）
- **セーブ**：`shared/save.js`（キー `3dgame:rpg`）。保存するのは「到達したステージ」と記録（撃破数・やられた回数・プレイ時間）だけ。ステージに入ったとき・やられたとき・ページを離れるとき（pagehide／タブが裏に回ったとき）と、45秒ごとに保存。「つづきから」はそのステージの入口から
- **HUD**：左上に HP／スタミナ／いまの目標（結界の残りと番人の残り数）、左下にスキル欄（クールダウン表示）、右下にミニマップ（迷路の壁・閉じた結界・出口・敵・自分）、ボス戦では上にボス HP バー

## ファイル構成

- `main.js` 起動のみ／`src/game.js` 全体の流れとメインループ／`src/area.js` エリア読込・結界・ゲート・調べる
- `src/player.js`（移動・ダッシュ・スタミナ・攻撃・回避・スキル）`src/enemies.js` `src/boss.js` `src/projectiles.js` `src/combat.js`
- `src/world/` エリアの形（build：共通・当たり判定、grid：当たり判定の升目分け、maze：迷路の生成と組み立て、dungeon：魔窟）、`src/models.js` キャラクターの形
- `src/ui/` HUD・頭上バー・看板の文、`src/effects.js` パーティクル・予兆・揺れ、`src/sound.js` SE と BGM
- `src/data/` プレイヤー・スタミナ・スキル・被ダメージ（player.js）、敵・AI・ボス（enemies.js）、エリアと迷路の設定（areas.js）、看板の文（dialogs.js）。調整用の数値はここに集約

## 決めたこと

- 「ステージ1・2」は旧仕様の村・草原の位置づけ。村は店・宿屋・NPC が不要になったので、まるごと迷路のステージに置き換えた
- 戦わずに先へ進めないよう、迷路はループのない完全迷路にし、正解ルート上の結界を番人の全滅で開ける仕組みにした（すり抜けて出口へ行けない）
- 迷路の形はシード固定で毎回同じ（覚えて上達できるように）。`src/data/areas.js` の `seed` を変えると別の形になる
- 迷路では壁越しにカメラが隠れにくいよう、視点の高さ（camPitch）を高めにしている（マウスで変更可）
- ボスの HP・防御は旧仕様のまま（HP 1400・防御 8）。旧 Lv4 の攻撃力で挑んだときと同じ手応えにするため
- 雑魚の HP は草原の3種は旧仕様のまま、魔窟の3種は攻撃が速くなった分だけ少し下げた（ガイコツ 85→70、亡霊 60→50、ゴーレム 140→110）
- スキルのクールダウンは旧仕様の 1.25 倍（回転斬り 4→5 秒、衝撃波 6→7.5 秒）。MP はない
- 旧セーブ（version 1、レベル制）を読んだときは、いた場所を新しいステージに置き換えて引き継ぐ（村→ステージ1、草原→ステージ2、魔窟→ステージ3）。記録（撃破数など）も引き継ぐ。知らない形式なら「つづきから」を出さない
- ボスを倒したら「つづきから」のデータは消し、クリア回数とベストタイムだけを残す
- Tab メニューは、装備・持ち物・クエストがなくなったので廃止した
- 開発用：URL に `?debug` を付けると `window.rpg` で状態を操作でき、ロック解除時の自動ポーズを無効化（自動テスト用）
- オンライン化に向けて：進行状態は `game.state.progress`（JSON）、入力は `readIntent()` で intent データにしてから `player.update(dt, intent)` へ、プレイヤーは `game.players` 配列＋`game.localIndex`（HP・スタミナはプレイヤーごと）、敵は最寄りのプレイヤーを狙う

## 改良内容（育成なしのシンプルなアクションへ）

1. レベル・経験値・MP・お金・ドロップ・回復薬・店・宿屋・クエスト・NPC 会話・Tab メニューを撤去
2. Shift ダッシュとスタミナゲージ（バテ状態）を追加
3. 被ダメージを最大 HP の割合に（雑魚 1/4、ボス 1/3）。雑魚の移動・攻撃を速く、攻撃間隔を短く
4. ステージ1・2を結界つきの迷路に作り替え（雑魚 20体・23体。旧草原は 18体）。ステージ3はレバー・宝箱を撤去
5. セーブを「到達したステージ」だけに（version 2。旧データは移行）。ページを離れるときにも保存
6. 敵が壁越しに気づかないよう視線判定を追加。当たり判定を升目分けして、壁が多い迷路でも軽くした
7. エリア破棄時に InstancedMesh のバッファも解放するようにした。敵 AI・ボスの調整値を `src/data` へ集約。毎フレームの intent 生成をやめた
8. エリアの仕掛け（たいまつの揺らぎ・ゲートの明滅・扉の開閉・結界の消え方）が動いていなかった不具合を修正（world.update を呼んでいなかった）
