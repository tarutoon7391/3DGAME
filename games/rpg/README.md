# 3DRPG 〜魔窟の主〜（games/rpg）

三人称視点のアクションRPG。はじまりの村で準備し、風の草原とダンジョン「魔窟」を抜けて、ボス「魔窟の主ガルドラ」を倒すとクリア。目安 30 分前後。

## 操作

| キー | 動作 |
|---|---|
| WASD／矢印 | 移動（カメラ基準） |
| マウス | カメラ（画面クリックで視点ロック。ロックしない場合は右ドラッグ） |
| ホイール | カメラ距離 |
| 左クリック | 攻撃（連打で3段コンボ。3段目は強攻撃） |
| Space | 回避（約0.4秒の無敵時間） |
| Q | 回転斬り（周囲攻撃／MP10・CD4秒） |
| E | 衝撃波（前方へ貫通する斬撃／MP16・CD6秒） |
| F | 話す・調べる（NPC・看板・薬草・レバー・宝箱） |
| Tab | メニュー（ステータス／装備／持ち物／クエスト） |
| 1 / 2 | 回復薬 / 魔力水 |
| Esc | ポーズ（視点ロック中はロック解除で自動的にポーズ） |

## 流れ

タイトル（操作説明・つづきから）→ 村で村長から討伐クエスト → 草原で10体討伐 → 報告するとボス討伐クエスト → 魔窟でレバー3つを動かして扉を開ける → ボス撃破でリザルト（プレイ時間・レベル等）→ 「はじめから遊ぶ」／ハブへ戻る。
全滅するとリザルト画面「全滅」→ 村の宿屋前で復活（所持金の30%を失う）。

## 仕様

- **エリア**：村（NPC 6人・店・宿屋・薬師）／草原（雑魚18体・薬草12か所）／魔窟（雑魚9体・レバー3つ・宝箱・ボス部屋）。エリア端の光るゲートに入ると暗転して遷移
- **敵**：近接（スライム／ガイコツ兵）、遠距離（ゴブリン弓兵／亡霊術師）、突進（イノシシ／岩ゴーレム）。攻撃前に体が赤く点滅し、地面に赤い予兆（扇・直線）が出る
- **ボス**：薙ぎ払い（前方扇）／魔弾の輪（全方位弾）／跳躍叩きつけ（着地点に赤円）。HP 50% で怒り（咆哮・行動が速くなる・叩きつけ後に弾・ガイコツ兵を召喚・魔弾が2波）
- **成長**：EXP でレベルアップ（最大20、HP/MP/攻撃/防御が上昇、全回復）。MP は自然回復
- **装備**：武器（木の剣→鉄の剣→聖騎士の剣）、防具（布の服→革の鎧→鋼の鎧）。店で売買。敵はゴールドと素材・薬を落とす
- **クエスト**：討伐（草原の魔物10体）／収集（薬草5・魔獣の牙3）／ボス討伐。HUD 左上に進行表示
- **セーブ**：`shared/save.js`（キー `3dgame:rpg`）。宿屋（泊まる・記録だけ）、エリア遷移・会話・レバー・宝箱の後、45秒ごとに自動セーブ。保存内容はレベル・EXP・HP/MP・所持金・所持品・装備・クエスト・エリアと位置・仕掛けの状態・プレイ時間
- **HUD**：HP/MP/EXP バー、レベル、ゴールド、クエスト、スキル欄（クールダウン表示）、ミニマップ（右下）、敵の頭上 HP、ボス HP バー

## ファイル構成

- `main.js` 起動のみ／`src/game.js` 全体の流れとメインループ／`src/area.js` エリア読込・ゲート・調べる
- `src/player.js` `src/enemies.js` `src/boss.js` `src/projectiles.js` `src/pickups.js` `src/combat.js`
- `src/world/` エリアの形（build・village・field・dungeon）、`src/models.js` キャラクターの形
- `src/ui/` HUD・頭上バー・会話/店・メニュー、`src/effects.js` パーティクル・予兆・揺れ、`src/sound.js` SE と BGM
- `src/data/` 敵・装備・レベル・クエスト・会話・エリア配置（数値はここに集約）

## 決めたこと

- 全滅時は「全滅」リザルトを出し、「村で目覚める」で村に復活（所持金 30% 減、HP/MP 全回復、レベル・装備・クエストは維持）
- ボスを倒したら「つづきから」のデータは消し、クリア回数とベストタイムだけを残す
- ボス戦中は自動セーブしない（ボス部屋の手前から再開）。ボスは全滅・再入場で全快に戻る
- 魔窟へのゲートはボス討伐クエスト受注（村長への討伐報告）まで閉じている
- スキルは最初から2つとも使える（MP とクールダウンで制限）
- 収集クエストの素材は報告時に消費する。装備中の武器・防具は売れない
- 視点ロックが外れたら自動でポーズ（Esc 1回でポーズになるように）
- 開発用：URL に `?debug` を付けると `window.rpg` で状態を操作でき、ロック解除時の自動ポーズを無効化（自動テスト用）
- オンライン化に向けて：進行状態は `game.state.progress`（JSON）、入力は `readIntent()` で intent データにしてから `player.update(dt, intent)` へ、プレイヤーは `game.players` 配列＋`game.localIndex`、敵は最寄りのプレイヤーを狙う
