# 3DRPG 〜魔窟の主〜（games/rpg）

一人称視点（V で三人称に切り替え可）のアクション。タイトルで2つのステージから選ぶ。**ステージ1「魔窟の主」**は迷路を進みながら魔物と戦い、奥にいるボス「魔窟の主ガルドラ」を倒せばクリア。**ステージ2「冥王の城」**は中ボス2連戦のあと冥王ザルヴァーンと戦う弾幕ボスラッシュ。育成（レベル・経験値）も、お金・アイテム・クエストもない。

## 操作

| キー | 動作 |
|---|---|
| WASD／矢印 | 移動（カメラ基準） |
| Shift | ダッシュ（押している間。スタミナを使う） |
| マウス | 視点（画面クリックで視点ロック。ロックしない場合は右ドラッグ） |
| V | 一人称／三人称の切り替え（はじめは一人称。選んだ方は保存される） |
| ホイール | カメラ距離（三人称のみ） |
| 左クリック | 通常攻撃（長押しで出し続ける。近接はコンボが続く） |
| Space | 回避（約0.4秒の無敵時間。スタミナを使う） |
| Q | 隼斬り（前へ踏み込む高速3連撃／クールダウン5秒） |
| E | 衝撃波（前方へ貫通する斬撃／クールダウン7.5秒） |
| F | 看板を調べる |
| Esc | ポーズ（視点ロック中はロック解除で自動的にポーズ） |

## 流れ

タイトル（操作説明・つづきから・ステージ選択）→
- ステージ1：1-1「迷いの森」→ 1-2「岩の迷宮」→ 1-3「魔窟」でガルドラ撃破 → リザルト
- ステージ2：「冥王の城」で中ボス2体 → 冥王撃破 → リザルト

リザルト（プレイ時間・撃破数・やられた回数）→「ステージNをもう一度」／「タイトルへ」／ハブへ戻る。
やられるとリザルト「やられてしまった……」→「入口からやり直す」で、いまのステージの入口から再挑戦（HP 全快、魔物・結界・ボスは元に戻る）。ステージ2だけは「部屋の前からやり直す」で、倒したボスの次の部屋の前から再挑戦（倒したボスは復活しない）。

## 仕様

- **1-1・1-2（迷路）**：シードから作る完全迷路（道が分かれて行き止まりも多いが、出口への正解ルートは1本）。正解ルート上に赤い**結界**が3つあり、そばにいる番人（2〜4体）を全部倒すと消える。脇道にも雑魚がうろつく。北端の青いゲートで次のステージへ
- **1-3（魔窟）**：旧仕様と同じ構造（入口通路・柱の大広間・ボス部屋）。レバーと宝箱は撤去し、ボス部屋の扉は最初から開いている。部屋に入ると扉が閉まって戦闘開始。ガルドラを倒すとステージ1クリア
- **ステージ2（冥王の城）**：入口通路（雑魚はいない）→ 中ボス1「業火の騎士イグニス」の間 → 中ボス2「氷霧の魔導士フロスガ」の間 → 冥王ザルヴァーンの間、と一直線。部屋に入ると後ろの扉が閉まり、ボスを倒すと奥の扉が開く。中ボスを倒すと HP が最大の 50% 回復し、残った弾と手下は消える。ステージ1より弾幕が多く、怒り（HP 50%）で弾の数が約1.3倍になる
- **プレイヤー**：能力値は固定（旧仕様の Lv4＋木の剣・布の服 相当。最大 HP 120、攻撃 15）。装備は変えられない
- **スタミナ**：最大 100。ダッシュ中は毎秒 22、回避1回で 30 減る。使わずに 0.6 秒たつと毎秒 30 回復。0 になると**バテ**：移動が 55% に落ち、ゲージが満タンに戻る（毎秒 22 回復、約4.5秒）まで回避もダッシュもできない。バテ中はゲージがオレンジになり「バテ！」と点滅する
- **被ダメージ**：雑魚の攻撃は1発で最大 HP の 1/4（30）、ボスの攻撃は1発で 1/3（40）。防御力の計算はない
- **回復**：回復薬はない。次のステージに入ったときと、やられて入口からやり直すときに HP が全快する
- **敵**：近接（スライム／ガイコツ兵）、遠距離（ゴブリン弓兵／亡霊術師）、突進（イノシシ／岩ゴーレム）。攻撃前に体が赤く点滅し、地面に赤い予兆（扇・直線）が出る。壁越しにはこちらに気づかず、見失うと最後に見た場所まで追ってくる
- **ガルドラ（ステージ1）**：薙ぎ払い（前方扇）／魔弾の輪（全方位弾）／跳躍叩きつけ（着地点に赤円）。HP 50% で怒り（咆哮・行動が速くなる・叩きつけ後に弾・ガイコツ兵を召喚・魔弾が2波）
- **ステージ2のボス**：攻撃の種類は 薙ぎ払い／跳躍叩きつけ（着地で弾の輪）／弾の輪（複数波）／扇弾（狙い撃ちを連射）／渦巻き弾（逆回りの2重もある）／突進（通った跡から左右に弾）／隕石（赤円が複数落ち、着弾点から弾が散る）。弾1発のダメージは最大 HP の 1/5（24）、近接・叩きつけ・突進・隕石は 1/3（40）
  - イグニス：近接型。薙ぎ払いのあと必ず扇弾で追撃、突進、2〜3波の輪
  - フロスガ：魔導士型。近づくと下がる。渦巻き（怒ると逆回りも追加）、扇弾、4波の輪、氷塊落とし、雹の雨
  - ザルヴァーン：全部入り。薙ぎ払いのあと輪で追撃、2重の渦巻き、怒るとさらに弾が増え、亡霊術師を召喚
- **セーブ**：`shared/save.js`（キー `3dgame:rpg`）。保存するのは「到達したステージ」「ステージ2で倒したボスの数（bossStep）」と記録（撃破数・やられた回数・プレイ時間）だけ。ステージに入ったとき・やられたとき・ページを離れるとき（pagehide／タブが裏に回ったとき）と、45秒ごとに保存。セーブ枠は1つで、「つづきから」は最後に遊んでいたステージ（エリア）の入口から。記録（クリア回数・ベストタイム）はステージ1が `records`、ステージ2が `records2`
- **視点**：既定は一人称（視野角 75°、上下 ±80°）。自分の体は描かず、画面右下に腕と手持ちの武器（ビューモデル）を出す。武器は職業ごとに専用の形（全96種。データは `src/data/weapons_a〜d.js`、組み立ては `src/weaponmodel.js`）で、持ち方は「立てて持つ（剣・杖など）／前へ構える（銃・弓など）／手にかぶせる（籠手・爪）」の3通り。通常攻撃（横薙ぎ2段・振り下ろし）・回転斬り・衝撃波・回避・ダッシュ・バテ・被弾でそれぞれ動く。体の向きは常に視点の水平方向で、攻撃も移動もその向きが基準。V で三人称（従来どおり）に切り替えられ、どちらを選んだかは保存される
- **プレイヤーの弾**：職業・技ごとに形が違う（矢・銃弾・音符・手裏剣・どくろなど63種。形は `src/data/shots_a.js`・`shots_b.js`、割り当ては `src/data/shots_map.js`、描画は `src/shotmodel.js`）。どの形を使うかは「撃った人の職業」と「弾の色（技の color）」で決まり、決めていない技は 爆発＝光の玉にとげ／貫通＝光の槍／それ以外＝光る玉
- **オーラ・エリアの見た目**（`src/auras.js`・`src/auratex.js`、数値は `src/data/auras.js`）：地面の塗り＋縁の線＋縁から立つ低い光の壁＋回る模様で範囲を見せる。模様は種類ごとに違う（回復＝十字／強化＝山形／守り＝六角／攻撃エリア＝とげ／吟遊詩人＝音符）。設置エリアは真ん中にマークが浮かび、残り時間が減ると光の壁が低くなり、最後の1.5秒は点滅。自分が味方のエリアに入ると明るくなる。僧侶（6m）と吟遊詩人（8m）の常時オーラも足元に出る。範囲回復・範囲強化を使うと、範囲いっぱいまで輪が広がる波紋が出る
- **敵の攻撃の見た目**（`src/enemyfx.js`、テーマと数値は `src/data/enemyfx.js`、敵専用の弾の形は `src/data/enemyshots.js`）：ボスごとにテーマ（炎・氷・冥界・鉄・大地・風・毒・水・羽・魔力・血・魔族・矢）を決め、そのボスの技の色の弾・衝撃波・壁をテーマの形で描く。衝撃波は「太い光の帯＋立ち上がる光＋テーマの飾り（炎・氷のとげ・冥火・岩など）」、着地・地割れ・火柱・吸い寄せの爆発には広がる衝撃、炎の壁などは下ほど濃い光と飾り。当たり判定はどれも今まで通り。赤い予兆は全テーマ共通のまま
- **味方の技エフェクト**（`src/skillfx.js`・`src/fxtex.js`、数値は `src/data/skillfx.js`）：扇の斬撃・回転斬り・突進の残像・着地の衝撃とひび割れ・光線・自己強化の光の柱・女神の祈りの大きな柱・ボスにかかる紋（弱体化・時間停止・印）・召喚陣・瞬間移動・とどめの十字斬り・メテオの尾と魔法陣・矢の雨・落雷。通常攻撃の剣の軌跡（段ごとに向きが変わり、最後は縦斬り）と、当たったときの光（会心は大きく金色）。バフ中の味方の足元には効果の種類ごとの色の紋（攻撃・守り・速さ・回復・盾・会心）。剣聖の一閃は縦横2枚の三日月の刃
- **技ごとの演出**：シールドバッシュは前に水色の六角の盾の壁を出して突撃。矢の雨は弓を真上へ向けて矢を放ち、少し遅れて（矢じり・羽根つきの）矢が降る。影分身中は一人称の左に薄い紫の手が出て少し遅れて同じ動き（追い打ち）をし、画面の縁が紫に光る（切れる1.5秒前から点滅）。疾風の旋律は楽譜の輪が二重に広がり色とりどりの音符が跳ねる（盛り上がる）、勇気の歌は灰がかった楽譜の輪がゆっくり広がり音符が沈んでいく（寂しげ）。精霊は目とほっぺのある水色のおばけ。岩巨人は投げられる距離（10m）まで歩き、地面から岩を引き抜いて頭の上へ持ち上げ、ボスへ投げつける（1回1.1秒、参加者の画面でも投げを再生）
- **一人称の手の動き**（`src/viewmodel.js`、振り方は武器の style）：槍は前へ突き（3段目は深く突いて光る）、回転斬りは真右から真左まで180度、格闘家は両手で構えて右左右左右の5連撃（気功波は両手で波動拳、昇竜拳は腕を真上へ、百裂拳は左右の高速連打と腕の残像）、狂戦士の振り下ろしと大地割りは刃を縦に、処刑人は1段目が鎌を反転・2段目そのまま・3段目は縦、魂刈りは反転して180度、死の宣告は一瞬で左右に何度も斬る。天穿ちは真上へ浮いて着地点に緑の印、槍を構えて急降下（跳ぶ技は一人称の視点も上がる）。時の鈍化はボスの上に針が逆に回る時計、時戻しは画面の縁に逆回りの時計、時間停止は画面が一瞬モノクロ・止まっている間ボスがモノクロで止まった時計。爆発する弾は火の玉と光と衝撃の輪（大砲・大爆発フラスコは大爆発）
- **罠士・侍・踊り子・吟遊詩人の演出**：罠士はクロスボウ（ボルトを撃つ）、トラバサミは歯つきのあごが開いた罠（踏まれるとバチンと閉じる）、爆薬罠は赤く点滅する地雷、罠の大地は腕を4回振り上げて地雷を放る（落ちてから見える）。侍の居合は真上へ振り上げて縦の一閃、見切りは左下の鞘へ刀を納めて構え、終わると素早く抜き戻す、燕返しは少し溜めてから左右に高速で斬り、最後は溜めた縦斬り（データの windup・lastGap）。踊り子の剣の舞は花びらが舞い、情熱のサンバは腕を揺らして踊って音符のオーラ。吟遊詩人の不協和音は歪んだ暗い音符がふらつきながら飛ぶ
- **雷術士・結界師・盗賊の演出**：落雷と雷嵐は一番近いボスの所へ。落雷は予告の魔法陣にイナヅマが走り、空から枝わかれした稲妻が落ちる。雷嵐は中にいる敵の足元から小さな雷がはじける。連鎖雷は当たった敵の所でスパークし、近くの敵へ稲妻が走る（全員の画面で）。時の鈍化は時計の針がゆっくり順に回る。守りの結界・大結界は盾マークの輪が広がり、バリア中は画面の縁が水色（大結界は青に近い水色）。結界の衝撃は杖をそのまま持ち上げて地面へ落とし、張ったバリアを砕いて攻撃（溜め 0.35 秒）。盗むは当たると画面に金の上矢印、煙玉は地面へ叩きつけて煙＋効果中は画面の縁に煙、大盤振る舞いはコインの輪と両手のばらまき（src/skillfx_d.js）
- **侍・占星術師・魔剣士の演出（2）**：見切りは鞘を出さず、ゆっくり左下へ納めて構える。成功すると左下から右へ思い切り抜き斬り（赤白の大きな斬撃と画面の一閃）。流れ星は光る小さな隕石が3つ、流星群は燃える大きな隕石がたくさん降る。星のカードは出たカード（太陽・月・風・星）のマークが画面に散らばる。魔力付与は剣を掲げ、効果中は一人称の剣に紫の魔力がまとわりつく（src/vmaura.js）。魔剣解放は剣を掲げて1秒魔力を溜め、紫の巨大な剣の残影で斬り下ろしてから刃を放つ（データの windup。src/skillfx_e.js）
- **竜人・道化師の演出**：竜人の3段目は縦斬り。竜の息吹は前へ炎を吐き続ける（1.4秒）。翼撃は竜の翼が生えてその場でゆっくり舞い上がり、2回羽ばたいて狙った場所へ斜めに急降下（2秒）。竜化は空から雷が降って周りを打ち（ダメージあり）、光の中で赤い竜に変身。竜の間は視点が高くなり、一人称は赤い腕と爪、息吹・翼撃も派手になる。切れるとゆっくり縮んで元に戻る（src/dragonform.js）。ジャグリング爆弾は3色の玉が右回りに回りながら飛び、1つずつ当たって爆発。手品は帽子から取り出す動き、大爆発は二重の爆発と紙吹雪、くす玉は赤十字の緑の帯、ハトは3方向へ3回。大道芸は両手を上げて紙吹雪、流星群は占星術師と同じ隕石、全員強化は吟遊詩人の楽譜の輪、大旋風は火のついた桜吹雪の炎の竜巻（src/skillfx_f.js）
- **聖騎士・拳銃使い・鎖鎌使いの演出**：聖騎士の3段目と聖撃は縦斬り（聖撃は天から光の柱）。神の盾は使った人の背中に天使の翼、盾が大きく金色に光り、羽マークの金の輪が広がる。効果中の味方は画面の縁が金色。拳銃は撃つたびに銃口が光り（ファニングも毎発）、デッドアイは着弾で小さく爆ぜる（見た目だけ）。ローリングは回避と同じ移動つき。鎖の飛びつきは鎖を投げて斜め上へ跳び、右上→左下へ振る。鎖縛りは鎖を投げてボスの体にらせんに巻きつく。鎖嵐は鎖が体のまわりを高速で回り、×字に斬りまくる（src/skillfx_g.js）
- **鎖鎌使いより後の職業の演出（レシピ式）**：暗黒騎士〜献身者の技は、data/skillvis.js の「技 ID → 演出のレシピ」から src/skillvis.js が組み立てて出す（一人称の動き・斬撃の向き・マークの輪・画面に散るマーク・爆発・稲妻・光の柱・網・吸い込みの渦・落ちてくる爆弾や槍や鷹・エリアに降る雨やナイフや花びらなど）。バフ中は画面の縁がバフごとの色に（BUFF_FRAMES）。剣・槌・斧の近接職は3段目が縦斬り（LAST_VERTICAL）、銃の職業は撃つと銃口が光る（GUN_JOBS。銃口の位置は武器の形から自動）。弾込め回避は回避の移動つき。演出を変えたいときはレシピを書きかえる
- **C キー（3つ目の通常技）**：全職業に C キーの技を追加（data/jobs_c.js。演出は data/skillvis_c.js）。クールダウン制で、HUD・スマホのボタン・職業の説明にも出る。多くは移動・防御・補助寄り。after で回避の移動・無敵・待ち時間短縮などを足せる。新しい汎用処理：recall（転送結界）・moveZones（トーテム・タレット・予言の移動）・dropZone・detonate・bloom・heartBoom・firewall・reviveShot・shiftHold・cycleSkip
- **一人称の見やすさ**：画面中央に照準。被弾すると画面の縁が赤く光り、視界の外からの攻撃なら画面中央の周りに方向の矢印が出る。足元の床に攻撃の予兆が出ている間は画面の縁がオレンジに点滅して「足元に攻撃の予兆！」と出る。床の予兆は一人称では濃くしている。ミニマップに見ている範囲（扇）を出す
- **HUD**：左上に HP／スタミナ／いまの目標（結界の残りと番人の残り数）、左下にスキル欄（クールダウン表示）、右下にミニマップ（迷路の壁・閉じた結界・出口・敵・自分）、ボス戦では上にボス HP バー

## 準備画面と頭上の表示

- 職業は16職ずつのタブ（1・2・3）に分け、小さなカードと「選んだ職業の説明」1か所にまとめて、スクロールしなくても収まるようにした（`src/ui/jobgrid.js`。全滅時の選び直しも同じ）
- ルームでは「準備完了」ボタンを押すと名前の右に緑のチェック。全員が準備完了するとホストが「出発！」を押せる
- ルームのステージは作った人（ホスト）のもの。別のステージの準備画面から合言葉で入ると、ホストのステージに切り替わる
- 近くの味方（30m 以内）とボスの頭上に名前と HP バー（`src/ui/nameplates.js`）。回復ができる職業（`healer`）で遊んでいると、HP 35% 以下か倒れた味方の札と体が赤く点滅する

## ステージ2：レイド（1〜8人の協力プレイ）

- タイトルの「ステージ2」→ 準備画面で名前と職業を選び、「ひとりで挑む」か「ルームを作る」（合言葉が出る）／合言葉を入れて「参加する」。ホストが「出発！」で全員一斉に始まる。途中参加もできる（今の部屋から）
- 部屋の構成：入口通路（雑魚なし・柱なし）→ 中ボス1 イグニス → 中ボス2 フロスガ → 冥王ザルヴァーン。誰かが部屋に入るとボスが目覚め、扉の外に残った人は部屋の中へ呼び寄せられる
- ボスを倒すと全員 HP 全回復（倒れていた人も蘇生）。回復薬はない
- 敵（ボス・雑魚）の HP は人数ごとの表で決まる（1人 1倍 → 4人 3.07倍 → 8人 6.14倍。`data/jobs.js` の `RAID_SCALE`）。どの人数でも、中ボスは3分前後、最後のボスは5分ほどで倒せる想定。ひとりで挑むときは敵の与ダメージが 0.7倍
- 倒れても協力プレイなら即終了ではない。仲間がそばに3秒立つと蘇生（HP 40%。だれでも同じ速さ）。全員倒れたら、全員の画面に職業の選び直し（8秒）が出て、そのあと「いま戦っているボスの部屋の前」から選んだ職業でやり直し（選ばなければ今の職業のまま。職業が変わった人の分身は他の人の画面でも作り直される）
- ひとりで挑んでやられたときも、ステージ2・3なら「職業を変えてやり直す」で選び直せる（`src/ui/jobpick.js`）
- 通信：自分のキャラは各自のブラウザで動かし（操作の遅れなし）、ボス・雑魚・召喚物はホストが動かして状態と演出（予兆・弾・音）を配る。弾と衝撃波の輪は各自が自分に当たったかを判定し、それ以外のボスの攻撃はホストが判定して本人へ伝える（`src/raid.js`）
- ホストが抜けたら残った人が自動で引き継ぎ、部屋の前からやり直す。接続が切れたらタイトルへ戻る
- チャット：ルームの準備画面（右の欄）と遊んでいる間に使える。PC は Enter で入力（Enter で送信・Esc でやめる）、スマホは 💬。定型文ボタン（よろしく！・回復おねがい など）もある。1回60文字まで
- 協力プレイ中はポーズしても世界は止まらない。ルームでの進行はセーブしない（ひとりで挑む場合だけ「つづきから」が残る）

### 職業96種（`src/data/jobs.js`。ステージ1 は剣士固定）

追加の16職（罠士〜鞭使い）の技は、`src/jobs.js` の汎用の型（`kind`：dash・burst・cone・shots・leap・zone・teambuff・selfbuff・teamheal・teamgauge・debuff・counter・random・beam・cleanse・mimic・cycle・blink・blinkbehind・mark。zone は field・strike・totem・trap・aegis・turret・talisman）をデータで組み合わせて作っている。新しい技はデータを書くだけで足せる。**技の id は全職で重ならないようにする**（重なると後から書いた方が上書きして、別の職業の技が化ける）。

- 基本ステータスはロール（アタッカー・ガンナー・タンク・ヒーラー・バッファー・デバッファー・ユニーク）ごとに共通で、攻撃力は全員 50（`data/roles.js`）。職ごとの差は技と特性、それに火力係数 `power`・支援係数 `support`（`data/jobs.js`）で付ける。数値は `tools/rpg-balance`（リポジトリ直下） の計測で決めている（方針と結果は `docs/balance/`）
- 敵の攻撃は固定ダメージ（攻撃の重さ × 110。`combat.js` の `ENEMY_HIT_BASE_HP`）。HP が多い職ほど実際に硬い。ステージ1 だけは剣士固定で調整してあるので従来どおり最大 HP の割合
- ヒーラーは僧侶が一番強い（Q 40%/10秒＋周囲 毎秒1% ≒ 毎秒 5%）。呪術師（吸血 3%・1回最大 1.5%、R は周り10mに合計 16%）・治癒拳士（殴った分の回復は 1.2秒ごと最大 2.5%、E は 12%/12秒）はその半分程度に抑えている
- ダメージ計算：防御は割合でカット（`攻撃力×倍率×30/(30+防御)`）。固定値引きだと1発の軽い攻撃（連射・多段）がほぼ 1 ダメージになっていたため

### 格闘家の追撃（C）

- Q・E・R の技が終わる前（少し猶予あり）に C を押すと、その技から派生した追撃が出る。単体や通常攻撃からは出せない。クールダウン6秒
- 気功波 → 気の玉と同じ速さで突っ込み（無敵）、着弾点で一撃。着いてから0.5秒も無敵
- 昇龍拳 → かかと落とし（ブレイク値が溜まりやすい）。出している間と着地後0.5秒は無敵
- 百烈拳 → 大きく強い気功波の3連発

### 回復・強化が誰に届くか

- 結界師の転送結界（C）は、置いた戻り先を消えるまで（20秒）足元に光の輪と柱で表示する。内側の輪が残り時間（自分の画面だけ）

- 一度きりで効く回復・強化の技（癒しの光・勇気の歌など）は、スキル欄の右上に「いま撃ったら届く人数（自分も含む）」が出る（回復は緑の ✚、強化は黄の ▲）
- 使える状態の回復・強化の技があると、届く範囲にいる仲間の足元に輪が出る（回復は緑、強化は黄）
- 置いておく回復の場や、数秒かけて回復する技は対象外

### 近接に意味を持たせる仕組み

- 近接職（通常攻撃が近接で、タンク以外）は、ボスの体の縁から6m以内にいる間「肉薄」：与ダメージ +15%・被ダメージ -25%（画面下に札が出る）。通常攻撃の振り始めに、前方の一番近い敵へ最大1.6m 踏み込む（三人称なら向きも合わせる）。数値は `src/data/player.js` の CLOSE

- **Q・E・R**：Q と E はクールダウン制のスキル（職業ごとに別の技）、R は必殺技
- **必殺ゲージ**：R は当てて溜めるゲージ制。通常攻撃は「1ヒットいくつ」ではなく「当て続けたら毎秒いくつ」で職業ごとに揃えている（近接 毎秒15＝約7秒、飛び道具 毎秒8＝約12.5秒で満タン）。1ヒットの量は職業ごとに自動で決まる（`data/jobs.js` の `basicGauge`。例：マシンガンナー 0.6・双子 1.6・剣士 6・ロケット兵 8・大槌使い 10.9）。盗賊・双剣士・ガンブレードは特色として 1.15〜1.3倍。技・継続ダメージ・設置物の小さなヒットは 2秒あたり合計 12 まで（多段・連射の技で一気に溜まらない）。魂刈り・早業・見切りなど狙って決めた大きな量はそのまま。通常攻撃から分かれた小さな弾はゲージなし。旧仕様の「クールダウンで撃てる衝撃波」はやめた
- **ブレイク**：ボスに当てるとブレイク値が溜まり、満タン（最大 HP の 22%）で4秒間 気絶・被ダメ 1.5倍。気絶系（ブレイク気絶・時間停止）はかかるたびに効く時間が ×0.7（最低 25%。ボスごとに回数を数える）。近接は飛び道具の約3倍溜まる（さらに重騎士 2倍・剣士 1.3倍）。殴らないと少しずつ減る。ボス HP バーの下の黄色いバー

### ステージ2 のボスの攻撃

弾だけでなく、近接の連撃・旋風・光線・地割れ・衝撃波の輪・ドーナツ範囲・引き寄せ・追尾する赤円・すき間のある壁・瞬間移動を織り交ぜる。弾は輪 12〜14 発・扇は 0.3 ラジアン以上あけて、すき間を走り抜けられる間隔にした。

| 攻撃 | 見分け方・よけ方 |
|---|---|
| 旋風 | 回転しながら追ってくる。離れて待つ（ブレイク中は止まる） |
| ドーナツ | 赤い輪の範囲＋緑の線。緑の内側（ボスの懐）が安全 |
| 引き寄せ→爆発 | 吸い寄せられる。ダッシュで範囲の外へ逃げる |
| 追尾する赤円 | 足元を少し遅れて追ってくる。走って振り切ってから止まると噴き上がる |
| 壁 | 部屋を横切る壁。1か所だけあるすき間をくぐる |
| 衝撃波の輪 | 広がる輪。回避の無敵でくぐる |
| 光線・地割れ・連撃・瞬間移動 | 赤い予兆の外へ／背後に回られたら振り向く |

- 弾・衝撃波の輪・壁・引き寄せは各自のブラウザで「自分に当たったか」を判定する（`src/hazards.js`）。それ以外はホストが判定する
- イグニス（中ボス1・HP 950）：薙ぎ払い→返し斬り→兜割りの3連撃、炎の大旋風、突進→旋風、爆炎陣（ドーナツ）、追い火柱、炎の壁、地割れ、波動、扇弾
- フロスガ（中ボス2・HP 820）：転移→波動、氷の渦潮（引き寄せ→爆発）、氷輪（ドーナツ）→波動、つらら追尾、氷壁、光線、渦、扇、輪、氷塊落とし、雹の雨
- ザルヴァーン（HP 1500）：上のほぼ全部＋冥刃の連携、冥光十字、怒ると亡霊術師を召喚
- 中ボスは攻撃の間隔を短く・動きを速く・1発を重くした（弾は最大 HP の 1/7、それ以外は 1/4.5）

## 敵の攻撃を消す技（src/erase.js）

弾を消す技（メイド・エクソシスト・踊り子・鎖鎌使い・マシンガンナー・鷹匠の掃除系、吸収術士・反射術士・分裂射手、重騎士の守護結界・鏡術師の鏡の盾／鏡の世界）は、範囲の中にある敵の攻撃をまとめて消す。

- 敵弾：消える（今までどおり）
- 時間差で落ちてくる範囲攻撃（隕石・噴火など）：中心が範囲内なら、その攻撃ごと消える
- それ以外（予兆つきの攻撃・なぎ払い・炎の壁・近接など）：消した範囲の「中だけ」当たらなくなる。範囲の外はそのまま当たる
- 安全な時間は、消した瞬間に範囲へかかっている予兆が終わるまで（0.6〜4秒）。地面に光る輪で見せ、輪の中では「足元に攻撃の予兆！」も出ない
- 結界系（守護結界・鏡の盾）は張った瞬間に1回消す。そのあとは今までどおり「入った敵弾を消す＋被ダメ半減」

## 決めたこと

- 「ステージ1・2」は旧仕様の村・草原の位置づけ。村は店・宿屋・NPC が不要になったので、まるごと迷路のステージに置き換えた
- 戦わずに先へ進めないよう、迷路はループのない完全迷路にし、正解ルート上の結界を番人の全滅で開ける仕組みにした（すり抜けて出口へ行けない）
- 迷路の形はシード固定で毎回同じ（覚えて上達できるように）。`src/data/areas.js` の `seed` を変えると別の形になる
- 迷路では壁越しにカメラが隠れにくいよう、三人称の視点の高さ（camPitch）を高めにしている（マウスで変更可）
- 一人称のビューモデルはカメラの子にして最後に描き、描く直前に深度を消す（shared/engine.js の描画は1回なので、別シーンを重ねる代わりにこうした）。壁に近づいても欠けない。目の位置はプレイヤーの当たり半径 0.5m の中心なので壁にめり込まず、ニアクリップは 0.05m
- 酔い対策：歩きの揺れは 3.5cm と控えめ、画面揺れは三人称の 0.45 倍。`src/data/view.js` の `bob`・`bobDash`・`fpsShake` を 0 にすると揺れなしになる。回転斬りでもカメラは回さず、腕だけを振る
- 視点の設定はセーブの `settings.view` に進行とは別に保存する（クリアしても残る）
- ボスの HP・防御は旧仕様のまま（HP 1400・防御 8）。旧 Lv4 の攻撃力で挑んだときと同じ手応えにするため
- 雑魚の HP は草原の3種は旧仕様のまま、魔窟の3種は攻撃が速くなった分だけ少し下げた（ガイコツ 85→70、亡霊 60→50、ゴーレム 140→110）
- スキルのクールダウンは旧仕様の 1.25 倍（回転斬り 4→5 秒、衝撃波 6→7.5 秒）。MP はない
- 旧セーブ（version 1、レベル制）を読んだときは、いた場所を新しいステージに置き換えて引き継ぐ（村→ステージ1、草原→ステージ2、魔窟→ステージ3）。記録（撃破数など）も引き継ぐ。知らない形式なら「つづきから」を出さない
- ボスを倒したら「つづきから」のデータは消し、クリア回数とベストタイムだけを残す
- Tab メニューは、装備・持ち物・クエストがなくなったので廃止した
- 開発用：URL に `?debug` を付けると `window.rpg` で状態を操作でき、ロック解除時の自動ポーズを無効化（自動テスト用）
- オンライン化に向けて：進行状態は `game.state.progress`（JSON）、入力は `readIntent()` で intent データにしてから `player.update(dt, intent)` へ、プレイヤーは `game.players` 配列＋`game.localIndex`（HP・スタミナはプレイヤーごと）、敵は最寄りのプレイヤーを狙う

## 改良内容2（一人称視点）

1. 一人称視点を追加して既定にした。V で三人称と切り替え、選んだ方を保存
2. 腕と剣のビューモデル（攻撃・回転斬り・衝撃波・回避・ダッシュ・バテ・被弾のアニメーション）
3. 照準・被弾時の赤い縁・視界外からの攻撃方向マーカー・足元の予兆の警告・一人称での予兆の強調・ミニマップの視野の扇
4. 一人称では体の向きを視点の水平方向に固定（攻撃判定もこの向き）
5. 感度・視野角・揺れなどを `src/data/view.js` に集約

## 改良内容（育成なしのシンプルなアクションへ）
