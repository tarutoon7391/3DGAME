# 3DRPG 〜魔窟の主〜（games/rpg）

一人称視点（V で三人称に切り替え可）のアクション。タイトルで2つのステージから選ぶ。**ステージ1「魔窟の主」**は迷路を進みながら魔物と戦い、奥にいるボス「魔窟の主ガルドラ」を倒せばクリア。**ステージ2「冥王の城」**は中ボス2連戦のあと冥王ザルヴァーンと戦う弾幕ボスラッシュ。育成（レベル・経験値）も、お金・アイテム・クエストもない。

## 操作

| キー | 動作 |
|---|---|
| WASD／矢印 | 移動（カメラ基準） |
| Shift | ダッシュ（押している間。スタミナを使う） |
| マウス | 視点（画面クリックで視点ロック。ロックしない場合は右ドラッグ） |
| V | 一人称／三人称の切り替え（はじめは一人称。選んだ方は保存される） |
| ホイール | カメラ距離（三人称のみ） |
| 左クリック | 攻撃（連打で3段コンボ。3段目は強攻撃） |
| Space | 回避（約0.4秒の無敵時間。スタミナを使う） |
| Q | 回転斬り（周囲攻撃／クールダウン5秒） |
| E | 衝撃波（前方へ貫通する斬撃／クールダウン7.5秒） |
| F | 看板を調べる |
| Esc | ポーズ（視点ロック中はロック解除で自動的にポーズ） |

## 流れ

タイトル（操作説明・つづきから・ステージ選択）→
- ステージ1：1-1「迷いの森」→ 1-2「岩の迷宮」→ 1-3「魔窟」でガルドラ撃破 → リザルト
- ステージ2：「冥王の城」で中ボス2体 → 冥王撃破 → リザルト

リザルト（プレイ時間・撃破数・やられた回数）→「ステージNをもう一度」／「タイトルへ」／ハブへ戻る。
やられるとリザルト「やられてしまった……」→「入口からやり直す」で、いまのステージの入口から再挑戦（HP 全快、魔物・結界・ボスは元に戻る）。ステージ2だけは「部屋の前からやり直す」で、倒したボスの次の部屋の前から再挑戦（倒したボスは復活しない）。

## 仕様

- **1-1・1-2（迷路）**：シードから作る完全迷路（道が分かれて行き止まりも多いが、出口への正解ルートは1本）。正解ルート上に赤い**結界**が3つあり、そばにいる番人（2〜4体）を全部倒すと消える。脇道にも雑魚がうろつく。北端の青いゲートで次のステージへ
- **1-3（魔窟）**：旧仕様と同じ構造（入口通路・柱の大広間・ボス部屋）。レバーと宝箱は撤去し、ボス部屋の扉は最初から開いている。部屋に入ると扉が閉まって戦闘開始。ガルドラを倒すとステージ1クリア
- **ステージ2（冥王の城）**：入口通路（雑魚はいない）→ 中ボス1「業火の騎士イグニス」の間 → 中ボス2「氷霧の魔導士フロスガ」の間 → 冥王ザルヴァーンの間、と一直線。部屋に入ると後ろの扉が閉まり、ボスを倒すと奥の扉が開く。中ボスを倒すと HP が最大の 50% 回復し、残った弾と手下は消える。ステージ1より弾幕が多く、怒り（HP 50%）で弾の数が約1.3倍になる
- **プレイヤー**：能力値は固定（旧仕様の Lv4＋木の剣・布の服 相当。最大 HP 120、攻撃 15）。装備は変えられない
- **スタミナ**：最大 100。ダッシュ中は毎秒 22、回避1回で 30 減る。使わずに 0.6 秒たつと毎秒 30 回復。0 になると**バテ**：移動が 55% に落ち、ゲージが満タンに戻る（毎秒 22 回復、約4.5秒）まで回避もダッシュもできない。バテ中はゲージがオレンジになり「バテ！」と点滅する
- **被ダメージ**：雑魚の攻撃は1発で最大 HP の 1/4（30）、ボスの攻撃は1発で 1/3（40）。防御力の計算はない
- **回復**：回復薬はない。次のステージに入ったときと、やられて入口からやり直すときに HP が全快する
- **敵**：近接（スライム／ガイコツ兵）、遠距離（ゴブリン弓兵／亡霊術師）、突進（イノシシ／岩ゴーレム）。攻撃前に体が赤く点滅し、地面に赤い予兆（扇・直線）が出る。壁越しにはこちらに気づかず、見失うと最後に見た場所まで追ってくる
- **ガルドラ（ステージ1）**：薙ぎ払い（前方扇）／魔弾の輪（全方位弾）／跳躍叩きつけ（着地点に赤円）。HP 50% で怒り（咆哮・行動が速くなる・叩きつけ後に弾・ガイコツ兵を召喚・魔弾が2波）
- **ステージ2のボス**：攻撃の種類は 薙ぎ払い／跳躍叩きつけ（着地で弾の輪）／弾の輪（複数波）／扇弾（狙い撃ちを連射）／渦巻き弾（逆回りの2重もある）／突進（通った跡から左右に弾）／隕石（赤円が複数落ち、着弾点から弾が散る）。弾1発のダメージは最大 HP の 1/5（24）、近接・叩きつけ・突進・隕石は 1/3（40）
  - イグニス：近接型。薙ぎ払いのあと必ず扇弾で追撃、突進、2〜3波の輪
  - フロスガ：魔導士型。近づくと下がる。渦巻き（怒ると逆回りも追加）、扇弾、4波の輪、氷塊落とし、雹の雨
  - ザルヴァーン：全部入り。薙ぎ払いのあと輪で追撃、2重の渦巻き、怒るとさらに弾が増え、亡霊術師を召喚
- **セーブ**：`shared/save.js`（キー `3dgame:rpg`）。保存するのは「到達したステージ」「ステージ2で倒したボスの数（bossStep）」と記録（撃破数・やられた回数・プレイ時間）だけ。ステージに入ったとき・やられたとき・ページを離れるとき（pagehide／タブが裏に回ったとき）と、45秒ごとに保存。セーブ枠は1つで、「つづきから」は最後に遊んでいたステージ（エリア）の入口から。記録（クリア回数・ベストタイム）はステージ1が `records`、ステージ2が `records2`
- **視点**：既定は一人称（視野角 75°、上下 ±80°）。自分の体は描かず、画面右下に腕と剣（ビューモデル）を出す。通常攻撃（横薙ぎ2段・振り下ろし）・回転斬り・衝撃波・回避・ダッシュ・バテ・被弾でそれぞれ動く。体の向きは常に視点の水平方向で、攻撃も移動もその向きが基準。V で三人称（従来どおり）に切り替えられ、どちらを選んだかは保存される
- **一人称の見やすさ**：画面中央に照準。被弾すると画面の縁が赤く光り、視界の外からの攻撃なら画面中央の周りに方向の矢印が出る。足元の床に攻撃の予兆が出ている間は画面の縁がオレンジに点滅して「足元に攻撃の予兆！」と出る。床の予兆は一人称では濃くしている。ミニマップに見ている範囲（扇）を出す
- **HUD**：左上に HP／スタミナ／いまの目標（結界の残りと番人の残り数）、左下にスキル欄（クールダウン表示）、右下にミニマップ（迷路の壁・閉じた結界・出口・敵・自分）、ボス戦では上にボス HP バー

## ステージ2：レイド（1〜8人の協力プレイ）

- タイトルの「ステージ2」→ 準備画面で名前と職業を選び、「ひとりで挑む」か「ルームを作る」（合言葉が出る）／合言葉を入れて「参加する」。ホストが「出発！」で全員一斉に始まる。途中参加もできる（今の部屋から）
- 部屋の構成：入口通路（雑魚なし・柱なし）→ 中ボス1 イグニス → 中ボス2 フロスガ → 冥王ザルヴァーン。誰かが部屋に入るとボスが目覚め、扉の外に残った人は部屋の中へ呼び寄せられる
- ボスを倒すと全員 HP 全回復（倒れていた人も蘇生）。回復薬はない
- ボスの HP は人数で増える（1人 1.0 → 4人 2.65倍 → 8人 4.85倍）
- 倒れても協力プレイなら即終了ではない。仲間がそばに3秒立つと蘇生（HP 40%。だれでも同じ速さ）。全員倒れたら3秒後に「いま戦っているボスの部屋の前」からやり直し
- 通信：自分のキャラは各自のブラウザで動かし（操作の遅れなし）、ボス・雑魚・召喚物はホストが動かして状態と演出（予兆・弾・音）を配る。弾と衝撃波の輪は各自が自分に当たったかを判定し、それ以外のボスの攻撃はホストが判定して本人へ伝える（`src/raid.js`）
- ホストが抜けたら残った人が自動で引き継ぎ、部屋の前からやり直す。接続が切れたらタイトルへ戻る
- 協力プレイ中はポーズしても世界は止まらない。ルームでの進行はセーブしない（ひとりで挑む場合だけ「つづきから」が残る）

### 近接に意味を持たせる仕組み

- **Q・E・R**：Q と E はクールダウン制のスキル（職業ごとに別の技）、R は必殺技
- **必殺ゲージ**：R は通常攻撃を当てて溜めるゲージ制（近接1発 9、飛び道具1発 4、スキル 3）。旧仕様の「クールダウンで撃てる衝撃波」はやめた
- **ブレイク**：ボスに当てるとブレイク値が溜まり、満タン（最大 HP の 22%）で4秒間 気絶・被ダメ 1.5倍。近接は飛び道具の約3倍溜まる（さらに重騎士 2倍・剣士 1.3倍）。殴らないと少しずつ減る。ボス HP バーの下の黄色いバー

### ステージ2 のボスの攻撃

弾だけでなく、近接の連撃・旋風・光線・地割れ・衝撃波の輪・ドーナツ範囲・引き寄せ・追尾する赤円・すき間のある壁・瞬間移動を織り交ぜる。弾は輪 12〜14 発・扇は 0.3 ラジアン以上あけて、すき間を走り抜けられる間隔にした。

| 攻撃 | 見分け方・よけ方 |
|---|---|
| 旋風 | 回転しながら追ってくる。離れて待つ（ブレイク中は止まる） |
| ドーナツ | 赤い輪の範囲＋緑の線。緑の内側（ボスの懐）が安全 |
| 引き寄せ→爆発 | 吸い寄せられる。ダッシュで範囲の外へ逃げる |
| 追尾する赤円 | 足元を少し遅れて追ってくる。走って振り切ってから止まると噴き上がる |
| 壁 | 部屋を横切る壁。1か所だけあるすき間をくぐる |
| 衝撃波の輪 | 広がる輪。回避の無敵でくぐる |
| 光線・地割れ・連撃・瞬間移動 | 赤い予兆の外へ／背後に回られたら振り向く |

- 弾・衝撃波の輪・壁・引き寄せは各自のブラウザで「自分に当たったか」を判定する（`src/hazards.js`）。それ以外はホストが判定する
- イグニス（中ボス1・HP 950）：薙ぎ払い→返し斬り→兜割りの3連撃、炎の大旋風、突進→旋風、爆炎陣（ドーナツ）、追い火柱、炎の壁、地割れ、波動、扇弾
- フロスガ（中ボス2・HP 820）：転移→波動、氷の渦潮（引き寄せ→爆発）、氷輪（ドーナツ）→波動、つらら追尾、氷壁、光線、渦、扇、輪、氷塊落とし、雹の雨
- ザルヴァーン（HP 1500）：上のほぼ全部＋冥刃の連携、冥光十字、怒ると亡霊術師を召喚
- 中ボスは攻撃の間隔を短く・動きを速く・1発を重くした（弾は最大 HP の 1/7、それ以外は 1/4.5）

  3. 毒の司祭ヴェクシス（HP 1300）：毒鎌→毒の環、毒沼の渦、毒の雨、毒の追跡、地割れ、十字光線、壁、輪・渦

## 決めたこと

- 「ステージ1・2」は旧仕様の村・草原の位置づけ。村は店・宿屋・NPC が不要になったので、まるごと迷路のステージに置き換えた
- 戦わずに先へ進めないよう、迷路はループのない完全迷路にし、正解ルート上の結界を番人の全滅で開ける仕組みにした（すり抜けて出口へ行けない）
- 迷路の形はシード固定で毎回同じ（覚えて上達できるように）。`src/data/areas.js` の `seed` を変えると別の形になる
- 迷路では壁越しにカメラが隠れにくいよう、三人称の視点の高さ（camPitch）を高めにしている（マウスで変更可）
- 一人称のビューモデルはカメラの子にして最後に描き、描く直前に深度を消す（shared/engine.js の描画は1回なので、別シーンを重ねる代わりにこうした）。壁に近づいても欠けない。目の位置はプレイヤーの当たり半径 0.5m の中心なので壁にめり込まず、ニアクリップは 0.05m
- 酔い対策：歩きの揺れは 3.5cm と控えめ、画面揺れは三人称の 0.45 倍。`src/data/view.js` の `bob`・`bobDash`・`fpsShake` を 0 にすると揺れなしになる。回転斬りでもカメラは回さず、腕だけを振る
- 視点の設定はセーブの `settings.view` に進行とは別に保存する（クリアしても残る）
- ボスの HP・防御は旧仕様のまま（HP 1400・防御 8）。旧 Lv4 の攻撃力で挑んだときと同じ手応えにするため
- 雑魚の HP は草原の3種は旧仕様のまま、魔窟の3種は攻撃が速くなった分だけ少し下げた（ガイコツ 85→70、亡霊 60→50、ゴーレム 140→110）
- スキルのクールダウンは旧仕様の 1.25 倍（回転斬り 4→5 秒、衝撃波 6→7.5 秒）。MP はない
- 旧セーブ（version 1、レベル制）を読んだときは、いた場所を新しいステージに置き換えて引き継ぐ（村→ステージ1、草原→ステージ2、魔窟→ステージ3）。記録（撃破数など）も引き継ぐ。知らない形式なら「つづきから」を出さない
- ボスを倒したら「つづきから」のデータは消し、クリア回数とベストタイムだけを残す
- Tab メニューは、装備・持ち物・クエストがなくなったので廃止した
- 開発用：URL に `?debug` を付けると `window.rpg` で状態を操作でき、ロック解除時の自動ポーズを無効化（自動テスト用）
- オンライン化に向けて：進行状態は `game.state.progress`（JSON）、入力は `readIntent()` で intent データにしてから `player.update(dt, intent)` へ、プレイヤーは `game.players` 配列＋`game.localIndex`（HP・スタミナはプレイヤーごと）、敵は最寄りのプレイヤーを狙う
