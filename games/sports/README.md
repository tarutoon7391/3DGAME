# 3Dスポーツ対戦（games/sports）

テニス・野球・アーチェリーの3競技から選んで CPU と対戦する。1競技 3〜5 分で決着。

## 流れ

タイトル（操作説明）→ 競技選択（戦績を表示）→ 難易度（やさしい・ふつう・つよい）→ 試合 → 結果（勝敗とスコア）→ 再戦／競技選択へ／ハブへ戻る

- Esc：試合中ポーズ（つづける／最初から／ハブへ戻る）
- M：ミュート切替
- 戦績（競技別の勝・敗・分とベストスコア）は `shared/save.js`（キー `3dgame:sports`）に保存し、競技選択に表示

## 操作

| 競技 | 操作 |
|---|---|
| テニス | WASD：移動　Space：ショット（打点に近いほど強く正確）　←→：左右打ち分け　Shift：ロブ　サーブ：Space でトス → もう一度 Space（頂点で打つほど良い） |
| 野球（打撃） | マウス：バットの芯（黄色の輪）　クリック：スイング（早いと引っ張り、遅いと流し。芯の上下で打球角度） |
| 野球（投球） | 1/2/3：球種（ストレート・カーブ・フォーク）　右下パネルの 3×3 マスをクリックで投球 |
| アーチェリー | マウス：狙い　長押し：引き絞り（引くほど・長く構えるほど手ブレ）　離す：発射 |

## 仕様

### テニス
- 後方視点。ボールは重力・バウンド・ネット判定つき。CPU の打球は着地予測マーカーを表示
- サーブあり（デュース／アドサイド交互、フォルト1回まで、ダブルフォルトで失点）
- アウト・ネット・ツーバウンドで失点。4ポイント先取で1ゲーム、3ゲーム先取で勝ち。ゲームごとにサーブ交代
- CPU は難易度で移動速度・反応・返球精度（狙いのブレ・ミス率）が変わる。アウトになる球は見送る

### 野球
- 3イニング制。表＝あなたの攻撃、裏＝CPU の攻撃。最終回表終了時に CPU がリードなら裏は無し、裏で勝ち越せばサヨナラ
- 打撃：タイミングと芯のズレで打球速度・角度・方向が決まり、落下点と野手の位置から アウト／ヒット／ツーベース／ホームラン／ファウル を判定。走者は塁上に表示し自動進塁
- 投球：球種3（変化の仕方と球速が違う）×コース9。端のマスはゾーンの縁にまたがりボールになりやすい
- CPU 打者は難易度（ミート率・パワー・ボール球の見極め）と、あなたの配球の傾向を覚える「読み」で打つ
- ボール・ストライク・アウトカウント、イニングごとの得点、塁の状況をスコアボードに表示

### アーチェリー
- 一人称。風（向き・強さを表示、毎射変わる）と重力で矢が流れる。矢の飛行はスロー＋追従カメラ
- 5射×3ラウンドの交互射ち。ラウンドごとに的が遠くなる（18m → 28m → 40m）
- CPU 対戦、または同一PC 2人交代プレイ（難易度は風の強さに効く）

## ファイル構成

- `main.js`：起動だけ
- `src/core/`：共通処理（app＝画面の流れ、menu＝競技選択・難易度、scoreboard、director＝カメラ演出、difficulty＝CPU 難易度係数、records＝戦績、fx＝パーティクル、sound＝効果音・BGM、env＝ライト・人物・観客・dispose、backdrop＝メニュー背景）
- `src/tennis/`：court（見た目）、physics（ボール物理・着地予測）、shots（プレイヤー操作・CPU）、game（ルール進行）
- `src/baseball/`：field（見た目・守備位置）、pitch（球種・コース・CPU 投手／打者）、outcome（打球判定・進塁）、pitchui（投球パネル）、view（カメラ・選手の動き）、game（ルール進行）
- `src/archery/`：range（見た目・弓・矢）、game（ルール進行・物理）

## 決めたこと

- テニス：デュースなし（4ポイント先取）。打ちやすさ優先でダブルスの横幅をインとする。サーブをノーバウンドで返すのは不可
- 野球：1イニング5点でチェンジ（試合時間を 3〜5 分に収めるため）。3回終了で同点なら引き分け。三塁打なし（長打はツーベース）。走者は安打の塁数だけ進み、二塁・三塁の走者は1つ余分に進む（シングルで二塁から生還）。アウト時は進まない（深いフライの犠牲フライのみ三塁走者が還る）。併殺なし
- 野球の右打者固定。投球パネルは投手の後ろから見た向き（画面右が内角）
- アーチェリー：的は半径 0.8m の10リング。2人対戦は勝敗の戦績に数えず、高い方の合計点をベストとして記録する
- ベストスコア：テニス＝最大ゲーム差、野球＝最多得点、アーチェリー＝最高合計点
- 照準はポインタロックを使わずマウスの位置で決める（Esc ポーズと衝突しないため）
- オンライン化（フェーズ3）に備え、各競技の状態は1つのオブジェクトにまとめ、入力はコマンド（データ）に変換してから状態更新に渡す。野球・アーチェリーはプレイヤーを配列で持つ
- 動作確認用に `?debug` を付けると `window.__sports` から状態を覗ける（通常時は何も出さない）
