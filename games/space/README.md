# 宇宙シューティング STARLANCE（games/space）

自機を後ろから見る3Dシューティング。前へ自動で進みながら、敵編隊と隕石を倒したり避けたりして、3つのステージのボスを倒す。

## 操作

| 操作 | キー |
|---|---|
| 上下左右に移動 | WASD／矢印キー |
| 照準 | マウス（画面上の照準マークの方向へ弾が飛ぶ） |
| 連射 | 左クリック（押している間） |
| ロール（ブースト回避） | 右クリック／Shift（約0.45秒無敵・クールダウン約1秒） |
| ボム | Space（敵弾を全部消す＋画面内の敵とボスの弱点にダメージ） |
| ポーズ | Esc（ウィンドウからフォーカスが外れたときも自動でポーズ） |
| 消音 | M |

## 流れ

タイトル（操作説明・難易度別ハイスコア）→ 難易度選択 → STAGE 1〜3（各ステージ約65秒＋ボス）→ リザルト（同じ難易度でリトライ／難易度を変える／タイトルへ／ハブへ戻る）

## 仕様

- **ステージ**：1 小惑星帯／2 敵艦隊／3 母艦内部。ステージごとに背景・フォグ・BGM を変えている。最後に WARNING 表示と警告音が出て、そのあとボスが登場する
- **ボス**（`src/data/bosses.js`）。弱点（光る部位）にだけダメージが通る。ほかの部位に当たった弾ははじかれる。HP が半分を切ると怒って攻撃が激しくなる（パターン追加・攻撃間隔 0.75 倍）
  - ガルガン：正面のコアが弱点。拡散リング／自機狙い3way／隕石投げ（後半は回転弾も使う）
  - ヴァルキス：左右のエンジンポッド2つを壊すと、艦橋のコアにダメージが通るようになる。隙間つきの弾幕の壁／高速の狙い撃ち連射／突撃機の射出（後半は回転弾も使う）
  - マザーコア：回転する装甲板がコアを守る。回転弾／拡散リング／高速の狙い撃ち連射（後半は弾幕の壁も使う）
- **敵**（`src/data/enemies.js`）：直進・蛇行・狙い撃ち（止まって撃ち、時間がたつと帰っていく）・突撃（止まって赤く点滅したあと、自機めがけて突っ込む）・隕石（壊せる）・鉄隕石（壊せない。弾をはじく）
- **出現**：`src/data/stages.js` のタイムラインで管理する（時刻・種類・隊形・数・ドロップ・難易度ごとの出し分け）
- **パワーアップ**：黄＝連射強化（Lv0〜3）、緑＝拡散弾（1→3→5→7方向）、青＝シールド（最大3枚）。決まった編隊を全滅させると出るほか、ふつうに倒した敵も 4.5% の確率で落とす。最大レベルのときに取ると +1000 点
- **ダメージ**：シールドが残っていれば1枚減るだけ。シールドが無いとライフが1減り、連射と拡散のレベルも1ずつ下がる（敵弾も全部消える）。ライフは3。0 になるとゲームオーバー
- **スコア**：撃破点 ×コンボ倍率（4コンボごとに +1、最大 ×8。2.5秒倒さないか、被弾するとリセット）×難易度倍率。ステージクリアボーナス＝1万×ステージ番号＋残りライフ×2000（ノーミスなら＋1万）。ボスの弱点を1つ壊すと +3000、撃破で +20000
- **ハイスコア**：難易度ごとに `shared/save.js`（キー `3dgame:space`）へ保存し、タイトルと難易度選択の画面に出す
- **難易度**（`src/data/difficulty.js`）：やさしい／ふつう／むずかしい。敵弾の速さ（0.72〜1.35 倍）、敵の発射頻度、出現数（0.75〜1.3 倍）、`min` 指定の追加編隊、ボスの攻撃間隔、ボスの HP、スコア倍率が変わる
- **演出**：流れる星とスピード線、エンジンの噴射（炎のコーンと粒）、爆発パーティクル、被弾したときの画面揺れと画面フラッシュ、ボス登場の WARNING、母艦内部では床に影が落ちる。効果音と BGM はすべて WebAudio で合成している

## 実装メモ

- 弾・敵・パーティクル・アイテムは `src/pool.js` の InstancedMesh プールで管理している（自機弾 320／敵弾 600／パーティクル 1800）。毎フレーム new しない
- 当たり判定は球で行う。速い自機弾は「線分と球」の判定にして、敵をすり抜けないようにしている
- 敵弾 350 発のとき、更新処理（描画を除く）は 1 フレームあたり約 0.4ms
- 入力の読み取り（`readControls`）と状態の更新（`player.update`）は分けてある。ゲームの進行状態は `g.state`（JSON にできる値だけ）にまとめた。プレイヤーは `g.players` 配列で持ち、操作対象は `g.localId` で選ぶ（将来のオンライン化に向けた努力目標）

## デバッグ用 URL パラメータ

- `?debug` … HUD に FPS と敵弾の数を出す。N キーでボス直前までスキップ。`window.__space`（状態）と `__space.step(dt)`（1フレーム進める）が使える
- `?debug&stage=2` … ステージ2から始める
- `?debug&stress` … 敵弾を常に250発以上に保つ（負荷確認用）

## 決めたこと

- 「前へ自動で進む」は、自機を z=0 に固定して周りの世界（星・背景・敵）を手前へ流す方式にした
- 難易度は shared のタイトル画面にボタンを増やせないため、「はじめる」を押したあとに専用の選択画面を出す方式にした（見た目は shared の CSS クラスを流用）
- ライフを失ったときは連射と拡散の両方を1段階下げる。シールドで受けたときはレベルを下げない
- ボムは初期3個・最大5個。ステージクリアで +1。ライフを失ったときに残りが2個未満なら2個まで補充する
- 「つづきから」は無し（1プレイ10分ほどのアーケード型のため）
